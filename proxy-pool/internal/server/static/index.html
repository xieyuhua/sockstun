测速
测速引擎core 会真实访问网络，只有能连通外网的节点才会被保留；tcp 仅验证端口可达
并发内核实例数越大越快，网络或机器较弱时建议调小
单节点探测超时例如 5s；线路较差可调大
最大可接受延迟毫秒，超过即判为不可用，0 表示不限制
延迟探测地址返回 204 的地址最合适；探测失败时程序会自动尝试其它候选地址
下载测速
启用下载测速测量节点实际下载速度，耗时更长
测速文件地址建议使用大文件地址
单节点测速时长例如 6s
下载测速节点数只对延迟最优的前 N 个节点测速，0 表示全部
最低速度MB/s，低于该值判为不可用，0 表示不限制
节点池与输出
节点池上限最终写入配置的节点数量上限，0 表示不限制
输出文件路径同时作为订阅地址对外提供
Clash 混合端口写入生成配置的 mixed-port
保留上一版备份替换前把旧配置另存为 clash.yaml.bak
定时任务
启用定时自动生成按下方规则自动执行「拉取 + 测速 + 生成」
cron 表达式5 字段：分 时 日 月 周，填写后优先于间隔；支持 @every 2h、@daily
时区解释 cron 时使用的时区，留空为本机时区
固定间隔未填写 cron 时生效，例如 30m
启动时自动生成一次服务启动后立即跑一轮
提示：内核缺失时会自动从 GitHub 下载 mihomo 到 bin 目录，可在配置文件中设置 gh_proxy 加速
